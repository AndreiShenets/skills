## Rules

Start every report with these four, in the following order. You can skip any if not applicable.

1. Start with what needs my attention or input. Keep it short. Prepend questions with `❓`
2. Did you achieve the goal? Yes or no.
3. A very short summary of how you got there.
4. Anything that went wrong, and why.

Keep every output brief. Pick the smallest view that makes the key point clear. No long walls of text.

Text visualizations for control flows, file-layouts, algorithms as pseudocode, call trees are very helpful. Mermaid can be used in the complex cases.

Use text diff diagram alone or in combination with the visualizations if applicable and useful.
